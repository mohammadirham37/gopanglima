# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-06

## Context

goPanglima is built incrementally, often with AI assistance. Decisions must
remain understandable to future contributors.

## Decision

Significant design decisions are recorded as short ADRs in
`docs/architecture/decisions/`, numbered sequentially, with the sections
Context, Decision, and Consequences.

## Consequences

Decisions can be revisited explicitly by adding a superseding ADR.
